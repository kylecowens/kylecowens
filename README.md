## About me

I’m **Kyle Cowens**, a Guernsey-based business owner and technology specialist.

I founded **Repaired Guernsey**, an independent electronics repair and technical services business. My work combines hands-on technical diagnostics with the operational systems required to run a reliable and well-documented business.

My wider technical interests include:

- Electronics diagnostics and repair
- ERPNext and business-process design
- Linux and Docker administration
- Self-hosted infrastructure
- OpenMediaVault and private cloud services
- Website development
- Networking and secure remote access
- Game-server administration
- Technical documentation and recovery planning
